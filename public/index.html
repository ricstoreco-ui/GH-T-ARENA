Panduan & FAQ

Bagaimana cara daftar turnamen?

Login/Register -> Buka menu Dash -> Buat Tim & Isi Roster -> Kembali ke Home -> Pilih Turnamen -> Daftar -> Pilih Tim -> Bayar via QRIS.

Apakah bisa ganti pemain?

Bisa, edit roster di Dashboard sebelum 1 jam jadwal turnamen dimulai.

Turnamen Offline itu apa?

Turnamen yang diadakan secara fisik (kopdar). Setelah daftar, kamu akan mendapatkan E-Ticket untuk di-scan panitia di lokasi.

Metode pembayaran apa saja?

Pendaftaran hanya via QRIS. Pencairan hadiah via DANA.

Bagaimana jika turnamen batal?

Dana akan dikembalikan 100% ke Saldo akun kamu (bisa ditarik ke DANA).
